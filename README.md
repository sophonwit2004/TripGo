# 🚀 TripGo Social — เว็บไซต์โซเชียลมีเดีย (Facebook + Instagram Hybrid)

> **โปรเจกต์ส่งอาจารย์ (Final Academic Project)**  
> เว็บแอปพลิเคชันโซเชียลมีเดียสายท่องเที่ยวและแชร์ไลฟ์สไตล์ที่ผสมผสานฟีเจอร์ที่ดีที่สุดของ **Facebook** และ **Instagram** เข้าด้วยกันอย่างสมบูรณ์แบบ ออกแบบให้รันบนเบราว์เซอร์ได้ทันที ใช้งานง่าย โค้ดสะอาด และบันทึกข้อมูลอย่างถาวร 100%

---

## 📌 คุณสมบัติเด่นของโปรเจกต์ (Key Features)

### 1. 🔐 ระบบสมาชิกและการจัดการโปรไฟล์ (Authentication & Profile)
- **สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ**: รองรับการระบุ Username, Password, Email และ Display Name
- **แก้ไขโปรไฟล์**: เปลี่ยนชื่อที่แสดง, ข้อความแนะนำตัว (Bio), รูปโปรไฟล์ (Avatar) และรูปภาพปก (Cover Photo)
- **การจำเซสชัน**: มีระบบ Session Management ข้อมูลผู้ใช้ไม่หลุดเมื่อรีเฟรชหน้าเว็บ

### 2. 📰 หน้าฟีดข่าวและการโต้ตอบ (News Feed & Interactive Posts)
- **การสร้างโพสต์ใหม่**: โพสต์ข้อความ พร้อมแนบรูปภาพสถานที่, ระบุจังหวัด/อำเภอ/ตำบล, พิกัด GPS ละติจูด-ลองจิจูด และแท็กแนะนำ (เช่น 📸 จุดถ่ายรูปสวย)
- **ระบบ Multi-Emoji Reactions**: กดถูกใจ/แสดงอารมณ์ใต้โพสต์ได้ 5 รูปแบบ (❤️ ได้ใจ, 😍 เลิฟเลย, 📍 พิกัดดี, 🔥 ฮอตสุด, 🌿 ชิลมาก)
- **ระบบความคิดเห็น (Comments)**: พิมพ์คอมเมนต์ใต้โพสต์ แสดงชื่อ รูป Avatar และเวลาที่คอมเมนต์
- **ระบบเช็คอิน (Check-in)**: กดเช็คอิน "ไปมาแล้ว!" บันทึกประวัติและอัปเดตสถิติสถานที่/จังหวัดที่เคยไป

### 3. 👥 ระบบสังคมและการติดตาม (Social & Follow System)
- **ค้นหาผู้ใช้งาน (Search)**: ค้นหาเพื่อนหรือผู้ใช้อื่นในระบบตามชื่อหรือ Username
- **กดติดตาม (Follow / Unfollow)**: กดติดตามผู้ใช้อื่นและแสดงจำนวนผู้ติดตาม/กำลังติดตามแบบ Real-time
- **หน้าโปรไฟล์ผู้ใช้ (User Profile Page)**: คลิกดูหน้าโปรไฟล์ของเพื่อน แสดงรูปปก รูป Avatar สถิติ และรายการโพสต์ทั้งหมดของผู้ใช้นั้น

### 4. 🌟 ฟีเจอร์เสริมพิเศษ (Bonus Features for Extra Credit)
- **Stories Bar (สตอรี่ชั่วคราวแบบ IG)**: แถบวงกลมแสดงภาพสตอรี่สถานที่ท่องเที่ยวเด่นๆ ด้านบนฟีด
- **ระบบแจ้งเตือน (Notifications)**: กระดิ่งแจ้งเตือนเมื่อมีคนมากดถูกใจ คอมเมนต์ หรือกดติดตามเรา
- **Dark Mode**: ปุ่มสลับโหมดมืด/โหมดสว่าง ถนอมสายตา และปรับธีมสีทั้งเว็บอย่างสวยงาม

## 🛠️ สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3 (CSS Variables, Flexbox, Grid, Dark Theme), JavaScript ES6+ (Async/Await, Fetch API, DOM Delegation)
- **Backend**: Python 3.14 + Django Framework (RESTful API Design)
- **Database**: **SQLite3** (`db.sqlite3`) — *ฐานข้อมูลไฟล์ในตัว ไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์แยก รันบนเครื่องไหนก็ใช้งานได้ทันที*
- **Data Persistence**: มีระบบสำรองข้อมูลใน `localStorage` ควบคู่กับ SQLite Database รับประกันว่า **โพสต์และข้อมูลไม่มีทางหาย** แม้จะกดปิดเบราว์เซอร์หรือรีเฟรช

## 📖 คำอธิบายโค้ดสำหรับนำไปพรีเซนต์อาจารย์ (Code Walkthrough)

### 1. 🗄️ `tripgo/models.py` (โครงสร้างฐานข้อมูล Database Schema)
- `Profile`: ข้อมูลโปรไฟล์ผู้ใช้เพิ่มเติม (bio, avatar_url, cover_url) เชื่อมต่อแบบ One-to-One กับ `User`
- `Pin`: ตารางเก็บโพสต์สถานที่ท่องเที่ยว (ชื่อ, จังหวัด, หมวดหมู่, รูปภาพ, ผู้สร้าง `created_by`, วันเวลา `created_at`)
- `PinLike`: ตารางเก็บการกดถูกใจและประเภทอีโมจิ (❤️, 😍, 📍, 🔥, 🌿)
- `PinComment`: ตารางเก็บความคิดเห็นใต้โพสต์
- `Follow`: ตารางเก็บความสัมพันธ์การกดติดตามระหว่างผู้ใช้ (`follower` -> `following`)
- `Story`: ตารางเก็บรูปภาพสตอรี่ 24 ชั่วโมง
- `Notification`: ตารางเก็บประวัติการแจ้งเตือนของผู้ใช้

### 2. ⚡ `tripgo/views.py` (การทำงานของ REST APIs)
- `serialize_pin()`: แปลงวัตถุ `Pin` จากฐานข้อมูลให้อยู่ในรูปแบบ JSON ที่มีข้อมูลครบถ้วน ส่งให้ Frontend แสดงผล
- `api_register()` / `api_login()` / `api_logout()`: จัดการการสมัครสมาชิก การยืนยันตัวตน (Authentication) และการจัดการเซสชัน
- `api_pins_list_create()`: ดึงรายการโพสต์ทั้งหมดตามลำดับเวลา และรับข้อมูลจากฟอร์มสร้างโพสต์ใหม่
- `api_follow_toggle()`: จัดการการกดติดตาม/ยกเลิกติดตาม พร้อมสร้างแจ้งเตือนส่งไปยังผู้ถูกติดตาม

### 3. 🎨 `index.html` (ระบบ Frontend & Client-side Logic)
- **Window Storage Polyfill**: เขียนโค้ดจำลองระบบ Storage ครอบ `localStorage` ของเบราว์เซอร์ ช่วยให้การบันทึกและโหลดข้อมูลแบบ Local เป็นไปอย่างราบรื่น
- **Event Delegation**: ใช้ระบบดักจับการคลิก (Click Delegation) ที่ระดับ document ช่วยให้ปุ่มโต้ตอบต่างๆ (ไลก์, คอมเมนต์, ลบ, แชร์, เช็คอิน) ทำงานได้อย่างมีประสิทธิภาพ ไม่ว่าจะเป็นโพสต์เก่าหรือโพสต์ที่เพิ่งสร้างใหม่
